# Dzen Editorial Engine

Автономная редакция для Дзена: 5 полноценных русскоязычных статей ежедневно по московскому времени.

## Расписание

| Москва | Тема |
|---|---|
| 09:00 | Комплаенс |
| 12:00 | Антифрод |
| 15:00 | OSINT |
| 18:00 | Новости России |
| 21:00 | Мировые новости |

## Pipeline

1. Tavily собирает актуальные материалы и первичные источники.
2. Gemini формирует самостоятельную статью на русском языке с проверяемыми ссылками.
3. Скрипт проверяет объём, структуру, количество источников и отсутствие пустых ссылок.
4. Статья сохраняется как HTML-страница в `docs/articles/`.
5. RSS 2.0 с полным текстом статьи обновляется в `docs/rss.xml`.
6. GitHub Pages раздаёт статьи и RSS. После подключения RSS в Студии Дзена платформа сможет забирать новые материалы.

## Важно о публикации в Дзене

Не следует считать, что у каждого автора есть открытый API прямой публикации. В этом проекте используется RSS как основной способ передачи полнотекстовых статей. Возможность подключения RSS зависит от доступных настроек и статуса канала в Студии Дзена. Пока RSS не подключён и не проверен, workflow только формирует и публикует фид на GitHub Pages; это ещё не подтверждение появления статьи в Дзене.

## GitHub Actions secrets

Добавить в Settings → Secrets and variables → Actions:

- `GEMINI_API_KEY` — ключ Google Gemini.
- `TAVILY_API_KEY` — ключ Tavily Search.

Секреты не хранятся в репозитории. Имена намеренно совпадают с используемыми в существующем Cloudflare Worker, но секреты Cloudflare и GitHub Actions — разные хранилища.

## Ручной запуск

Actions → Dzen Editorial Engine → Run workflow. Ручной запуск по умолчанию работает в `dry_run=true` и не меняет RSS. Для реальной генерации выбрать `dry_run=false`.

## Контроль качества

- Минимум 4 500 символов без HTML-разметки.
- Не менее трёх источников с уникальными доменами.
- Ссылки на источники встроены в материал.
- Для новостей проверяется актуальность событий; даты и числа не выдумываются.
- При недостатке надёжных источников публикация пропускается, а не заполняется предположениями.
- Дедупликация по дате, слоту и теме.
- Существующие материалы не перезаписываются.
